# 重みの組の見直し(2026-10-02)

利用者の指示「設定を変えたり少しいじるだけで格段に上がる商材が多いはず。1つずつ確かめて進める」による見直し。
裏の目標は、全商材の大成功率を上げること。

## やり方

1. 追加した160商材(元の9商材は除く)に、エンジンにある10の重みの組を当てた。
   - `ITEM_PARAMS` の5組: far・farB・farT・farM・tight
   - 元の商材の重みを写した5組: kim(輝紋章の盾)・kham(光の鍛冶ハンマー)・hid(超ようせいのひだね)・
     orb(虹色のオーブ)・yum(幽紋刀)
2. ふるい分け: `tools/analyze.js --replace 1 --params 組`(商材の重みを置き換える)で、乱数テープ・種44・各1000局を打ち、
   今の設定と同じ局どうしで比べた。商材ごとに一番良い組を選び、z≥3 の66商材を候補にした。
3. 確かめ: 10組から選ぶと偶然が混ざるので、選ぶのに使っていない種55・各2000局で、今の設定と比べ直した。
   z≥2 だった64商材に入れた。
4. 入れた後のエンジン(`--params` 無し)で、64商材とも、確かめた時の記録と同じ打ち方になること(種55の最初の300局)、
   `node tests/sim.js` が基準と一致すること(元の9商材は変わらない)を確かめた。

## 結果

- 64商材で、種55の大成功率が +3.6〜+21.4pt。合計 691.6pt で、169商材の平均にすると +4.1pt(先読み無し)。
- 光の鍛冶ハンマーの組(kham)が26商材と一番多い。うち22商材が光の地金で、集中力変化・倍半の商材も2つずつある。
- 難航していたレイヴンサイズ(35.9% → 56.6%)・ウィズダムサイス(37.6% → 59.0%)も入った。
  ただし到達率は 73〜76% で、まだ届かない局が多い。
- 入れなかった: 超鍛冶ハンマー(tight、z=1.87)・魔衛隊士のかぶと(yum、z=1.47)。
- 先読みありの率は測っていない。

## 小さな変更の見直し(組を入れた後)

- 今の設定(入れた組)の上で、重みを1つだけ動かす8通りを、追加160商材に当てた(種44・各1000局、同じ局どうし)。
  火力上げ(heat を +4・0)、本会心の価値(cap を 0.75倍・1.5倍)、遅れたマスの優先(pr を 0.75倍)、
  温度の費用(tcost を 0・0.017)、光ったマスへの備え(litReady を2倍)。商材ごとに今の値と同じになる変更は除いた(計1087通り)。
- z≥3 は3商材だけだった。1087通りを比べたので、偶然でも1〜2件は出る数で、**小さな変更はほとんど効かない**
  (入れた組が、その周りでは一番良い位置にある)。
- 種55・各2000局で確かめて入れた(`engine.js` の `ITEM_PARAM_ADD`):

  | 商材 | 組 | 変更 | 種55 | 片方だけ | z |
  |---|---|---|---|---|---|
  | ガナドールバンド | kham | heat 0 → 4 | 65.3% → 69.8% | 375対465 | 3.11 |
  | セレーネアックス | hid | heat 1 → 0 | 55.0% → 56.4% | 51対80 | 2.53 |

- 黄金の飾り弓(cap 18)は種55で差なし(z=0.38)で入れていない。
- まだ低い商材(影星の短刀・スコーピオサイス・ネビュラスブレード・ヴェーレダガーなど)は、組の入れ替えでも小さな変更でも
  はっきり良くならなかった。重みではなく、打ち方の仕組み(エンジン)の側の改善が要る。
