# メタリオンサイズの調査(2026-10-02)

武器鍛冶の鎌「メタリオンサイズ」(職人Lv75・装備Lv135・地金特性 集中力変化)について、
大成功の許容誤差・打ち方の参考を調べ、推奨手の大成功率を上げた記録。

## 1. 盤面

縦4行×横2列のうち5マス(右の列の下3つは使わない)。

| マス | ゾーン |
|---|---|
| a(左上) | 130〜138 |
| b(右上) | 230〜238 |
| c(左・2行目) | 370〜379 |
| d(左・3行目) | 170〜178 |
| e(左・4行目) | 300〜308 |

ゾーンの下限の合計は1200。超4連打ち・4連打ちは [a,b,c]・[c,d]・[d,e]、上下打ちは [a,c]・[c,d]・[d,e]、
ななめ打ちは [b,c]、左右打ちは [a,b] に打てる。値の大きい c・e が左の列にあり、2マス技か1マス技でしか打てない。

## 2. 大成功の許容誤差

**分からなかった。** エンジンでは5のまま(使うマスの数から決めた値)にしている。

- 公式ガイドブック「氷の領界+職人の極意編 Ver3.2[後期]」の種類ごとの表
  ([mi-mi-dqx の記事](https://mi-mi-dqx.blazeworks.jp/archives/4728))に鎌は無い。鎌は Ver5.0 で追加された。
- 次も探したが、鎌の値は見つからなかった。
  - 攻略サイト: [魚おじのドラ10奮闘記](https://cidmogero.com/2021/02/13/shokunin-daiseiko/)、
    [ラグナのブログ](https://dq10ragu.com/post-20585)、[ゲーム乱舞](https://gameranbu.jp/dq10/3a60814d5c71527c7ce3)、
    [ドラクエ10極限攻略の鎌のページ](https://xn--10-yg4a1a3kyh.jp/a_buki/dq10_buki_k_reibunsaizu.html) など
  - 冒険者の広場の日誌(鍛冶・鎌の打ち方)
  - [meluce.jp の職人ツール](https://meluce.jp/flyby/dqx/)(データに許容誤差の項目が無い)
  - DQ10大辞典(wikiwiki.jp)は、この作業の環境からは閲覧を拒否されて読めなかった。
- 誤差の数え方(2017-04-05 の修正。[鍛冶シミュのお知らせ](https://mi-mi-dqx.blazeworks.jp/%E3%80%8C%E9%8D%9B%E5%86%B6%E3%82%B7%E3%83%9F%E3%83%A5-for-dqx%E3%80%8D%E3%81%AE%E4%B8%8D%E5%85%B7%E5%90%88%E3%81%A8%E3%83%90%E3%83%BC%E3%82%B8%E3%83%A7%E3%83%B3%E3%82%A2%E3%83%83%E3%83%97%E3%81%AE)、
  [誤差4問題](https://mi-mi-dqx.blazeworks.jp/archives/4515)): ゾーン内のマスは差が5以上でも4、ゾーン外のマスは差が8以下でも9。
  エンジンの `MAX_ERR`(4)・`OVER_ERR_MIN`(9)と同じ。
- 推測の材料(確かではない): 表では、同じマスの数でも盤面が広がった形は1多い。

  | マスの数 | 寄った形 | 広がった形 |
  |---|---|---|
  | 3 | (縦1列の片手剣・ウデ・木工刀、L字のルアーとも 2。差なし) | |
  | 4 | 正方形の盾・アタマ・ツメ・錬金ランプ 3 | 縦長のヤリ・L字の足 4 |
  | 5 | 2×2+1の鍛冶ハンマー 5 | 真ん中が空いたブーメラン 6 |

  鎌は縦4行に広がった形なので6の可能性もあるが、3マスでは形による差が無い。
- 5と6のどちらで打っても、ほとんど変わらない(下の「4」を参照)。少ない方の5で打てば、本当が6の時に
  損をしない。ゲームで確かめられたら `engine.js` の `CRAFT_TOL` に `鎌` を足す。

## 3. 打ち方の参考(熟練者の手順)

- [セーラスサイズの手順](https://hiroba.dqx.jp/sc/diary/795064260487/view/8045255/)(パキラクリスの冒険日誌、
  同じ鎌・同じ集中変化・同じ盤面の形): 1600℃の半減ターンで火力上げ → 1900℃から b・a に熱風を1回ずつ×2 →
  1600℃で超4連 → 2150℃で b に熱風。1800℃・1400℃(会心ターン)の熱風で会心を狙い、1000℃か600℃で上下ねらい打ち。
  d・e も高温のうちに伸ばす。c は4連以上の集中力の効率で寄せる。
- [ステラトルネードの手順](https://hiroba.dqx.jp/sc/diary/795064260487/view/8031826/)(同じ日誌、5マス・集中変化):
  会心ターンは熱風以外で使い、熱風は通常ターンで使う。1400℃と1000℃で会心を狙う。
- [地金別の基本的な打ち方 集中変化 戻り編](https://hiroba.dqx.jp/sc/diary/532221286233/view/6232270/)(ウェロアの冒険日誌):
  寄せる時は半減ターン、狙う時は1.5倍ターン。火力上げ2回で1600℃の半減に超4連 → 1550℃で火力上げ2回 →
  2150℃で熱風 → 2000℃の半減をもう一度使う。

これらの序盤をそのままエンジンに決め打ちさせる比較もしたが、良くならなかった(下の「5」)。

## 4. 結果(先読み無し、tools/analyze.js、乱数テープ・同じ局どうし)

選ぶのに使っていない種55・3000局:

| 重み | 大成功 | 届かない | 超過 | 誤差超え | 許容誤差が6なら |
|---|---|---|---|---|---|
| 既定 | 24.8% | 50.0% | 2.1% | 23.1% | 29.0% |
| farT | 31.0% | 19.3% | 13.9% | 38.1% | 37.8% |
| **farM(今回入れた組)** | **40.1%** | **2.7%** | 3.9% | 53.4% | 49.0% |

- 既定 → farM: 片方だけ大成功 411局対870局(z=12.82)。farT → farM: 523局対794局(z=7.47)。
- farM の中身と決めた順は `engine.js` の `ITEM_PARAMS` の上のコメントにある。
- 許容誤差を5のつもりで打っても6のつもりで打っても、6で数えた大成功率はほぼ同じ
  (種22・1000局 45.5% / 45.7%、片方だけ 3局対5局)。
- 先読みありの率は測っていない。

## 5. 効かなかった案(同じ局どうし1000局)

| 案 | 結果 |
|---|---|
| 2マス残りの総当たり(ldp2、幽紋刀の設定) | 32.9% → 32.2%(z=-0.48)、超過が増える |
| 会心ターンに着くのに本会心を狙えるマスが無い手を減点する | +0.6〜0.9pt(z≤0.6) |
| 火力上げを決める基準(50℃あたりの前進の見込み 28)を 22・18 にする | z≤0.55、超過が 3%→11% |
| 本会心を狙う余裕の判定に残り距離を使う | 4: ±0 / 5: +0.5pt |
| 2マス同時の本会心に残り距離の判定(psEff) | 大成功かどうかが変わった局は無い(到達は 92.8% → 93.1%) |
| 熟練者の序盤を決め打ちする(5通り) | 到達は上がるものもあるが、大成功は同じか悪化(z=-4.0〜-0.1) |

## 6. 全商材への広がり(続きの作業)

- boostEff(案A)を集中力変化の全55商材の既定にした比較(種44・各1000局): 4 で 390局対430局(z=1.40)、
  5 で 68局対84局(z=1.30)。悪くなる商材は無いが全体の上がり幅は小さいので、既定にはせず、
  効く商材の重みに個別に入れる。
- 先読み無しで大成功50%未満の61商材(戻り以外、種44)の失敗の内訳: 届かない 6.7% / 超過 5.3% /
  **誤差超え 46.2%**。全体の底上げには、届かせる改善より仕上げの精度の改善が要る。
  誤差超えの局では、本会心を狙える位置なのにふつうの技で入れる手が1局に0.71回あり、その時の誤差0は17%だった。
